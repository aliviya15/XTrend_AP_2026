# XTrend – Smart Crypto Trading & Market Intelligence Platform

XTrend is an academic database project focused on cryptocurrency market analysis, trading signals, relational database design, and SQL query optimization.

## Objectives
- Analyze cryptocurrency market trends.
- Identify bullish and bearish EMA crossover signals.
- Store cryptocurrency and trading signal data.
- Perform SQL-based market analysis.
- Evaluate database query performance.

## Key Features
- Cryptocurrency tracking.
- EMA-based trend analysis.
- Bullish and bearish signal identification.
- Trading signal history.
- SQL queries for market analysis.
- Query execution and performance analysis.

## Technology Stack
- PostgreSQL
- SQL
- Python (where implemented)
- Git and GitHub

## Database
The project includes relational database design, schema implementation, data management, analytical queries, and query performance evaluation.

## Query Optimization
PostgreSQL `EXPLAIN ANALYZE` is used to inspect query execution plans and evaluate query performance.

## Project Structure
- `dbms/` – Database design and implementation
- `dbms/plans/` – Query execution plans
- `dbms/05_query_timings.md` – Query timing analysis
